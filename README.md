# 🔱 Maa Kushmanda - Day 4 Python Sketch

A real-time cinematic animation project built with Python and Pygame to celebrate the **4th day of Navratri (Maa Kushmanda)**. It features dynamic weapon multiplications, sequential fly-in assets, a full-screen divine flash explosion, and a smooth 3D parallax breathing reveal effect.

---

## 🚀 Quick Start Guide

### 1. Clone the Repository
Run the following command in your terminal to clone this project:
```bash
git clone https://github.com
cd Day-4-python-sketch
```

### 2. Install Dependencies
Make sure you have Python installed, then install the required graphics libraries:
```bash
pip install pygame pillow
```

### 3. Run the Animation
Launch the real-time presentation window using:
```bash
python day4.py
```

## 🎬 How the Animation Works (Timeline)
1. **Trishul Rise & Split:** One giant Trishul rises up, splits into 5 units, spins rapidly with neon golden rays, and vanishes.
2. **Weapons Entry:** The remaining 6 sacred weapons fly in one-by-one to form a perfect circle.
3. **The Implosion:** All weapons orbit together and compress tightly into a single center point.
4. **The Divine Reveal:** A full-screen white-gold explosion flash triggers a screen-shake, revealing Maa Kushmanda with an independent floating 3D breathing effect.
